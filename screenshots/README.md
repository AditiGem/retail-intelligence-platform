# Dashboard Screenshots

Capture and place your actual high-resolution dashboard screenshots here:

1. `01_executive_dashboard.png` — Main dashboard showing the 6 core KPI cards, top 10 products chart, and daily revenue trend.
2. `02_sales_forecasting.png` — Sales forecast section showing the 7-day projection table and Plotly forecast chart.
3. `03_sql_analytics.png` — SQL Analytics Showcase page showing query expanders and live results table.
4. `04_data_explorer.png` — Data Explorer page showing filterable data table and export controls.

### How to capture on Windows:
1. Run `streamlit run retail_platform.py`
2. Open `http://localhost:8501` in your browser.
3. Press `Win + Shift + S` to take clean snips of each view.
4. Save the images to this `screenshots/` directory.
